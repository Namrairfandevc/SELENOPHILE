# Selenophile

A sleek, responsive social media web application developed as a single-page interactive experience. **Selenophile** features a unique dynamic UI that cycles through distinct color themes on every user interaction.

## 🚀 Features

* **User Authentication**: Full sign-up and login system using browser local storage.
* **Interactive Feed**: View stories and posts, like content, and interact with the community.
* **Discovery**: Explore page to find new content and trends.
* **Real-time Messaging**: Direct messaging interface to stay connected with friends.
* **Profile Management**: Customizable user profiles with editable bios and profile pictures.
* **Dynamic Theming**: An "every-click" theme engine that rotates between Dark Red, Purple, Blue, and Green modes.
* **Responsive Design**: Optimized for a seamless experience across desktop and mobile devices.

## 🛠️ Tech Stack

* **HTML5**: Semantic structure and layout.
* **CSS3**: Advanced styling, animations, and dynamic variable-based theming.
* **JavaScript (ES6+)**: Core application logic, state management, and DOM manipulation.
* **LocalStorage API**: For persistent client-side data storage.

## 📂 Installation & Usage

Since this is a lightweight, single-file application, no complex installation is required:

1.  **Clone the Repository**:
    ```bash
    git clone [https://github.com/your-username/selenophile.git](https://github.com/your-username/selenophile.git)
    ```
2.  **Launch**:
    Open the `index.html` file in any modern web browser.
